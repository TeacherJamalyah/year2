GitHub Pages Export Guide

Publish your game to the web for free in 2 minutes!

Langkah 1: Salin Kod (Copy Code)

Tekan butang Copy Complete HTML Code di bawah untuk menyalin keseluruhan kod permainan ini ke dalam papan klip (*clipboard* anda).

Langkah 2: Buat Repositori di GitHub

  1. Buka github.com dan log masuk.
  2. Tekan ikon "+" di penjuru kanan atas lalu pilih "New repository".
  3. Namakan repositori (contoh: year2-english-game).
  4. Pilih tetapan Public dan tandakan kotak "Add a README file", kemudian tekan Create repository.

Langkah 3: Tambah Fail index.html

  1. Di dalam repositori anda, tekan butang Add file > Create new file.
  2. Namakan fail sebagai index.html.
  3. Tampal (*paste*) kod yang disalin tadi ke dalam ruang editor fail tersebut.
  4. Tekan butang hijau Commit changes... di penjuru atas kanan.

Langkah 4: Aktifkan GitHub Pages

  1. Pergi ke tab Settings di bahagian atas repositori anda.
  2. Di menu sebelah kiri, klik pada Pages.
  3. Di bahagian Branch, tukar daripada None kepada main (atau master), kemudian klik Save.
  4. Tunggu selama 1 minit. Pautan (*link*) permainan anda akan dipaparkan di bahagian atas halaman Pages tersebut!
